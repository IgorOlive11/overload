# Segurança

## Como relatar uma falha

Não abra uma issue pública para relatar uma falha de segurança. Use a opção "Report a vulnerability" na aba Security deste repositório, que manda o relato de forma privada para o dono do repositório.

Inclua no relato:

- o que a falha permite fazer;
- os passos para reproduzir;
- a versão ou o commit em que ela aparece.

## Escopo

Valem relatos sobre o app publicado a partir deste repositório, sobre as políticas de acesso do banco e sobre as Edge Functions. Não teste falhas usando contas ou dados de outras pessoas.
