# Contribuindo

O Overload é um projeto aberto, mas não recebe contribuições de terceiros. Só o dono do repositório abre issues e pull requests, porque o desenvolvimento segue um processo com agentes de IA e um único Product Owner, que não foi pensado para receber trabalho de fora.

## O que você pode fazer

- **Usar, estudar e fazer fork.** É para isso que o código é aberto, sob a [AGPL-3.0-or-later](LICENSE). Se publicar uma versão modificada, a licença pede que o código dela também fique aberto.
- **Relatar uma falha de segurança, de forma privada.** Siga o [SECURITY.md](SECURITY.md). É a única exceção.

## O que não é aceito

Issues e pull requests de terceiros não podem ser abertos neste repositório.

## Como o projeto é construído

O fluxo completo está em [docs/tecnico/processo-de-desenvolvimento.md](docs/tecnico/processo-de-desenvolvimento.md), e as regras dos agentes estão no [AGENTS.md](AGENTS.md).
